# Python 基础与自动化

这是当前学习主线的可运行入口。课程页面在桌面浏览器中打开，练习代码由本机的 CPython 执行，不会上传到远程服务。

当前版本提供一个代表课节，用来跑通完整学习循环：阅读、动手编写、运行反馈、从空白重建和记录掌握状态。

## 快速开始

### 1. 准备环境

需要安装：

- Node.js 24 或更高版本
- CPython 3.12 或更高版本
- 一款现代桌面浏览器

在 PowerShell 中检查版本：

```powershell
node --version
python --version
```

如果两条命令都能输出符合要求的版本号，就可以启动课程。

### 2. 启动本地课程

在仓库根目录打开 PowerShell，然后运行：

```powershell
cd python/interactive-course
npm start
```

当前课程没有第三方运行时依赖，首次启动也不需要执行 `npm install`。

看到以下输出后，不要关闭这个终端：

```text
Python 课程已启动：http://127.0.0.1:8010
```

在桌面浏览器中打开：

<http://127.0.0.1:8010>

## 页面怎么用

桌面页面分为三个主要区域：

- 左侧“课程目录”：选择课节，并查看未开始、已练习或已掌握状态。
- 课节内容：阅读本节目标、讲解、参考示例和提示。
- 练习工作区：在代码编辑区作答，在运行结果区查看反馈。

完成一个课节时，按以下顺序操作：

1. 阅读本节目标，确认函数需要接收什么、返回什么。
2. 查看讲解和参考示例，理解做法后再开始写代码。
3. 在“你的 Python 代码”编辑区修改起始代码。
4. 点击“运行练习”。
5. 根据运行结果修改代码，直到状态显示 `passed`。
6. 清空编辑区，不复制参考示例，独立重新写出完整答案。
7. 再次点击“运行练习”，确认重写后的答案仍然通过。
8. 勾选“我已从空白文件独立重建”，把课节标记为已掌握。

“已练习”表示代码至少通过过一次。“已掌握”表示你确认自己完成了从空白重建。勾选掌握状态不会代替运行验证。

## 怎么看运行结果

| 状态 | 含义 | 应该怎么做 |
| --- | --- | --- |
| `passed` | 当前答案通过课节检查 | 清空代码并独立重建一次 |
| `compile_error` | 存在语法、缩进或制表符错误 | 从错误信息标出的文件和行号开始修改 |
| `test_failed` | 代码能运行，但返回结果不符合要求 | 对照题目检查返回值和边界情况 |
| `runtime_error` | 运行过程中抛出异常 | 查看异常类型和调用位置 |
| `timeout` | 运行超过 5 秒 | 检查无限循环或无法结束的逻辑 |
| `runner_unavailable` | 本地 Python 无法启动 | 检查 Python 安装或配置解释器路径 |

页面无法连接课程服务时，会显示连接失败提示。确认运行 `npm start` 的终端仍然打开，然后刷新页面。

## 进度保存在哪里

以下内容会自动保存在浏览器的本地存储中：

- 当前打开的课节
- 每个课节的代码草稿
- 已练习状态
- 已掌握状态

刷新页面或关闭后重新打开，进度会自动恢复。恢复进度需要使用相同的浏览器配置、主机和端口。更换端口、清除网站数据或使用无痕窗口后，原进度不会出现在新页面中。

## 停止课程

回到运行 `npm start` 的终端，按：

```text
Ctrl+C
```

服务停止后，已经保存在浏览器中的学习进度仍会保留。

## 指定 Python 路径

如果 `python --version` 无法运行，但电脑上已经安装了 Python，可以先定位解释器：

```powershell
py -0p
```

然后在启动课程的同一个 PowerShell 窗口中设置解释器完整路径。把示例路径替换为你电脑上的真实路径：

```powershell
$env:PYTHON_COURSE_PYTHON_PATH = "C:\Path\To\Python\python.exe"
cd python/interactive-course
npm start
```

该设置只影响当前 PowerShell 窗口。需要取消时运行：

```powershell
Remove-Item Env:PYTHON_COURSE_PYTHON_PATH
```

## 更换端口

默认端口 `8010` 被占用时，在启动课程前设置其他端口：

```powershell
$env:PORT = "8011"
cd python/interactive-course
npm start
```

然后打开终端输出的新地址，例如 <http://127.0.0.1:8011>。

需要恢复默认端口时运行：

```powershell
Remove-Item Env:PORT
```

## 常见问题

### `npm start` 提示 Node.js 版本不符合要求

运行 `node --version`。课程要求 Node.js 24 或更高版本，升级后重新打开 PowerShell 再启动。

### 页面能打开，但运行练习时找不到 Python

运行 `python --version`。如果只有 `py` 命令可用，先用 `py -0p` 找到解释器完整路径，再按上文设置 `PYTHON_COURSE_PYTHON_PATH`。

### 启动时提示 `EADDRINUSE`

端口已被其他程序占用。按“更换端口”一节设置 `PORT`，重新启动后打开新地址。

### 页面提示无法加载课程或无法连接执行服务

确认 `npm start` 没有停止或报错，并使用终端实际输出的地址访问。服务只监听本机 `127.0.0.1`，不能从其他设备访问。

### 运行结果一直是 `timeout`

检查 `while`、递归或其他循环是否能结束。单次练习的执行时间上限为 5 秒。

### 切换端口后进度变成空白

浏览器会把不同端口视为不同站点。回到原端口可以看到原进度；也可以在新端口重新开始。

## 推荐学习方式

本地课程用于练习和检验，不需要替代完整教材。建议按以下循环学习：

1. 用主线课程学习一个概念。
2. 不复制示例，自己完成练习。
3. 根据错误反馈修正代码。
4. 从空白文件重建一次。
5. 把同一概念用到一个小型真实任务中。

推荐主线课程：

- [University of Helsinki Python Programming MOOC](https://www.mooc.fi/en/courses/)：练习密集，适合作为系统主线。
- [Harvard CS50P](https://cs50.harvard.edu/python/)：讲解清晰，适合补充概念和形成完整认识。

仓库内的长期学习安排见 [`roadmap.md`](roadmap.md)，资料清单见 [`resources.md`](resources.md)。完成 Python 基础阶段后，再按根目录 [`README.md`](../README.md) 的顺序进入 Go 和 Rust。
