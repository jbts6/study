# 学习目录

推荐按 Python、Go、Rust 的顺序学习。三套本地交互课程都已有可运行入口：Go 提供 22 节，Rust 提供 12 节。

- Python：`cd python/interactive-course && npm start`
- Go 后端：`cd go/interactive-course && go run ./cmd/server --addr 127.0.0.1:8080 --runner-mode local`
- Go 前端（另开终端）：`cd go/interactive-course/web && npm ci && npm run dev -- --host 127.0.0.1`
- Rust：`cd rust/interactive-course && npm start`
