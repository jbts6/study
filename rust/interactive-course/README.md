# Rust 交互式课程

这是一个本地运行的 Rust 练习环境，提供课程导航、代码草稿、运行反馈和 12 节可提前浏览的课程。目录会提示推荐学习顺序，只有通过隐藏测试的课节才会记录为完成。

## 环境要求

- Node.js 24 或更高版本
- Rust stable 工具链，且 `cargo` 已加入 PATH

执行器会在临时目录创建 Cargo 项目，只运行本机课程服务提供的隐藏测试。它适合本地学习，不应直接暴露到公网或用于运行不受信任的代码。

## 启动

```text
cd rust/interactive-course
npm test
npm start
```

浏览器打开 <http://127.0.0.1:5173>。

首次调用 Cargo 时，工具链和系统冷启动可能明显较慢；课程执行器已为这段启动时间预留 15 秒。

## 目录结构

- `web/`：课程页、响应式样式和浏览器端进度状态
- `server/`：课程目录加载、静态文件服务和执行接口
- `internal/course/`：课程定义、示例代码、起始代码和隐藏测试
- `test/`：目录契约、HTTP、执行器、浏览器状态和课程内容测试

课程接口为：

- `GET /api/course`：返回已脱敏的课程目录和每节公开练习
- `POST /api/execute`：提交 `{ "lessonId": "...", "code": "..." }` 执行当前练习

隐藏测试只从服务端课程目录加载，不会通过课程目录接口发送到浏览器。
