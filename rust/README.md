# Rust 学习入口

本目录保留 Rust 课程原有的系统资料，并新增了可直接运行的交互式课程。

## 先开始练习

进入 [`interactive-course/`](./interactive-course/)，按其中的说明启动本地课程页。课程包含 12 节按顺序解锁的练习，浏览器会保存完成进度和代码草稿，提交代码后由本机 `cargo test` 执行公开示例对应的隐藏测试。

## 课程资料

- [`course.md`](./course.md)：Rust 语言课程正文
- [`roadmap.md`](./roadmap.md)：学习路线和阶段目标
- [`project-tutorial.md`](./project-tutorial.md)：项目实战教程
- [`resources.md`](./resources.md)：配套资源

交互式课程用于高频练习和即时反馈，Markdown 资料用于完整讲解、复习和项目延伸。
