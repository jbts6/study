# Rust 本地完整课程修订计划

## 背景

上一版把 GitHub 学习项目整理成了本地资源索引，课程文件主要提供入口和链接，内容密度不足，不能替换用户原有的本地 Rust 课程。本次修订将本地文档恢复为“可直接学习”的主体，GitHub 仓库只作为延伸阅读、练习平台或源码参考。

## 目标

- 在 `rust/course.md` 中提供从工具链到异步工程的连续教程。
- 每个核心章节都包含概念说明、原创 Rust 示例、练习目标、常见报错和完成检查点。
- 在 `rust/roadmap.md` 中提供可按周执行的学习安排，而不是只列阶段名称。
- 在 `rust/project-tutorial.md` 中提供一个可以跟着实现的完整项目，覆盖建包、建模、错误处理、测试和异步扩展。
- 保留 GitHub 项目链接，但明确它们对应的使用时机，避免把链接当成课程正文。

## 分工与提交边界

1. `rust/course.md`：课程正文，独立提交。
2. `rust/roadmap.md`：学习计划与验收方式，独立提交。
3. `rust/project-tutorial.md`：项目实战教程，独立提交。
4. `rust/resources.md`：资源使用指南，独立提交。
5. 主代理执行最终一致性检查、修复交叉引用并提交验证结果。

每个 worker 只修改自己负责的文件，不回退其他 worker 或用户已有的改动。所有示例使用原创内容，不复制上游教程或仓库的解答文本。

## 内容验收标准

- `course.md` 至少包含 10 个连续章节，且每章同时出现“目标/示例/练习/常见报错或排错/检查点”中的对应内容。
- `course.md` 有不少于 20 个 Rust 代码块，覆盖所有权、借用、`Result`、trait、迭代器、线程或异步等核心主题。
- `roadmap.md` 至少包含 6 个阶段和可执行的日/周任务，每阶段有明确产出与完成标准。
- `project-tutorial.md` 包含项目目录、关键数据结构、命令行操作、测试策略和至少一个完整可运行的主流程示例。
- `resources.md` 说明每个主要 GitHub 项目的使用时机，并能回指本地课程章节。
- 所有本地相对链接有效，Markdown 无明显断裂，文档只保留 ASCII 代码标点与正常中文正文。
- 不引入 Cargo 依赖或外部代码文件；教程中的命令和代码片段应在说明中标明运行上下文。

## 验证命令

```text
git diff --check
按脚本统计 Markdown 行数、标题、Rust 代码块、练习和检查点数量
校验 rust/ 下相对链接目标存在
检查旧版“只有入口/只有链接”的短文案是否仍是正文主体
git status --short -- rust docs/superpowers/plans
```
