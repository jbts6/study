# Python 课程连续学习导航设计

## 摘要

课程页面保留自然的正文滚动，同时让桌面端课程目录保持在视口内。练习通过后，在当前工作区直接提供“下一课”按钮。学习者无需回到页面顶部，也不会在查看运行结果前被自动切走。

## 问题

课程共有 18 节，正文和练习工作区组成一个长页面。当前左侧目录随页面一起滚动，离开顶部后无法继续选课。练习通过只会解锁下一节，不会在当前位置提供继续入口。学习者必须向上滚动较长距离，才能进入下一课。

## 目标

- 桌面端滚动长课节时，课程目录始终可达。
- 通过当前练习后，可在工作区直接进入下一课。
- 保留当前运行结果，只有学习者主动点击后才切换。
- 切换课节后从新课标题开始阅读，并保持清晰的键盘焦点。
- 不改变课程内容、解锁规则、进度数据结构和 Runner。

## 方案比较

### 采用：粘性目录与上下文下一课按钮

左侧目录使用粘性定位和独立纵向滚动。正文继续使用浏览器页面滚动。通过后，工作区操作区显示下一课按钮。

这个方案直接解决两个断点，且不改变现有页面阅读模型。目录内部只在内容超过视口时滚动，不会让正文进入嵌套滚动容器。

### 不采用：固定双栏并让正文独立滚动

该方案能让顶栏和目录始终固定，但会形成多个常驻滚动区域。长讲解、代码编辑器和运行结果之间的滚动关系更复杂，键盘和触控板操作也更容易落入错误容器。

### 不采用：固定在视口底部的全局操作条

该方案让下一课始终可见，但会持续占用编辑器和结果区域的垂直空间。课程只需要在通过后显示继续动作，没有必要常驻一个全局操作条。

## 交互设计

### 左侧课程目录

- 仅在宽度大于 720px 的桌面布局启用粘性定位。
- 目录到达视口顶部后保持可见，高度不超过当前视口。
- 18 节内容超出可用高度时，目录自身纵向滚动。
- 页面重新渲染进度和状态时，保留目录的滚动位置。
- 切换课节后，当前课节在目录中保持可见，但不强制跳到目录顶部。
- 720px 及以下继续使用现有横向课程目录，不增加纵向粘性区域。

### 下一课按钮

- 当前课节未通过时不显示。
- 当前课节已进入 `practiced[]` 且存在下一节时显示。
- 文案为“下一课：第 N 课 · {课节标题}”。
- 按钮位于练习操作区，与“运行练习”和掌握复选框处于同一操作上下文。
- 点击后保存当前草稿和进度，切换到下一课，清空上一课运行结果。
- 页面滚动到新课主内容起点；焦点移到主内容区域，辅助技术能够读取新标题。
- 运行练习期间按钮禁用，避免并发切换课节。

### 最后一课

最后一课通过后不显示无效按钮。操作区改为显示“已完成全部 18 节”，明确课程已经结束。

### 失败与锁定状态

- `compile_error`、`test_failed`、`runtime_error`、`timeout`、`runner_unavailable` 和请求失败均不显示下一课按钮。
- 未解锁课节仍可阅读，但不能运行；本次变更不修改该规则。
- 已通过课节在刷新后仍显示下一课按钮，因为显示条件来自持久化的 `practiced[]`。

## 实现映射

### HTML

在现有 `.actions` 中增加：

- `#next-lesson-button`：原生按钮，默认隐藏。
- `#course-complete`：完成提示，默认隐藏。

不增加浮层、对话框或新的页面区块。

### JavaScript

- 在纯视图模块中增加课程推进计算函数，根据课节顺序、当前课节和 `practiced[]` 返回下一课或完成状态。
- `CourseApp` 只消费该结果并更新按钮、完成提示和禁用状态。
- 目录渲染前记录滚动位置，渲染后恢复；课节切换后让活动项进入最近可见区域。
- 所有课节切换统一滚动主内容到顶部并恢复主内容焦点。

### CSS

- 桌面端为课程目录增加 `position: sticky`、视口高度限制和 `overflow-y: auto`。
- 下一课按钮沿用现有强调色与 44px 最小点击高度，不建立新的颜色或圆角体系。
- 完成提示使用成功语义色，同时保留明确文字。
- 移动断点撤销目录粘性和纵向高度限制。
- 动效仅使用现有 160ms 反馈，并继续遵守 `prefers-reduced-motion`。

## 测试策略

先写失败测试，再实现：

- 未通过当前课节时不提供下一课。
- 已通过中间课节时返回顺序中的下一课。
- 已通过最后一课时返回课程完成状态。
- 下一课必须来自课程既定顺序，不依赖模块边界。

实现后运行 `python/interactive-course` 的限定视图测试，再运行该课程的 13 项测试。视觉检查覆盖 1280×800 下的长正文、目录内部滚动、通过后按钮、最后一课完成态和 720px 以下原有横向目录。

## 验收标准

- 在 1280×800 视口滚动到练习工作区后，左侧课程目录仍可使用。
- 目录内部滚动后，运行练习和更新掌握状态不会把目录重置到顶部。
- 当前练习通过后，无需向上滚动即可看到并使用下一课按钮。
- 点击下一课后，新课标题进入视口，主内容获得焦点，目录活动项可见。
- 最后一课通过后显示完整课程完成提示。
- 原有逐节解锁、本地草稿和刷新恢复行为不变。
- 不增加第三方运行时依赖，不修改 `rpg/`、`go/` 或 `rust/`。

## 非目标

- 不自动切换课节。
- 不重做课程主题、字体、配色或正文结构。
- 不增加上一课、搜索、目录折叠或模块筛选。
- 不改变移动端课程目录的信息架构。
