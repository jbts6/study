# 玩家关卡文件版本化重置

## 目标

当 Python RPG 的关卡代码接口发生不兼容更新时，自动重置工作区内
`python-rpg/` 的玩家关卡文件，避免旧模板缺少必需回调而无法推进任务。

## 范围

- 使用工作区状态记录玩家文件模板版本。
- 版本缺失或低于当前版本时，删除并重建整个 `python-rpg/` 目录。
- 重建六个关卡文件，并将已打开关卡编辑器替换为对应的新起始代码。
- 保留世界战役的任务进度与解锁状态。

不处理兼容接口的常规内容更新，也不保留旧模板中的玩家代码。

## 设计

定义 `PLAYER_FILESET_VERSION` 作为当前模板接口版本，并为 Python 战役使用
独立的工作区状态键。打开游戏时，在创建会话与读取玩家代码之前比较已记录版本。

若版本不匹配，重置流程按以下顺序执行：

1. 递归删除工作区中的 `python-rpg/` 目录。
2. 按关卡顺序写入当前 `starterCode`，重建目录与六个 Python 文件。
3. 替换已打开关卡文档的全文，确保本次运行读取新代码。
4. 写入模板版本并展示一次重置提示。

只有步骤 1 至 3 都成功时才写入版本。任一步失败时，保持旧版本标记，报告错误并中止本次游戏启动；下次打开仍会重试重置。

战役存档继续由 `WorkspaceWorldSaveStore` 管理，不参与该流程。

## 验证

- 旧版本或无版本标记会重建玩家目录、替换已打开文件并写入版本。
- 当前版本不会重复重置，保留玩家文件。
- 重置失败时不更新版本标记，也不继续打开游戏。
