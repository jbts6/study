# Python 交互课程内容补全设计

日期：2026-08-19

状态：设计已确认，等待书面规格审阅

## 摘要

将 `python/interactive-course/` 从单节演示课程扩展为完整、自包含的 Python 基础与自动化课程。课程面向已有前端或其他语言经验、但尚未系统学习 Python 的学习者，共 18 节、4 个模块，预计学习时间 22～26 小时。

课程只使用 Python 标准库。前 14 节建立 Python 表达、程序组织、文件处理和可靠性能力；后 4 节逐步完成单文件本地日志审计器。每节均提供结构化讲解、前端类比、短示例、常见错误、引导练习、分级提示、参考实现、自动验收和项目关联。学习者无需打开外部教材即可完成课程。

## 背景与问题

当前 Python 交互课程只有一节“用函数汇总日志”。运行服务、课程目录、页面、草稿保存和隐藏测试已经可用，但课程仍是能力骨架，而不是完整学习产品。相比之下，Go 和 Rust 交互课程分别已有 22 节和 12 节。

现有页面仅把 `explanation` 渲染为单个纯文本段落。即使直接增加课节数量，也无法承载系统讲解、错误示例和练习步骤。因此本次补全同时扩展课程内容契约和页面呈现，但不替换现有本地执行架构。

Python RPG 六关是选修综合项目，不属于本课程内容补全范围。

## 目标学习者

学习者具备前端或其他编程语言经验，但对 Python 的语法、标准库和工程习惯缺少系统认识。

课程不重复解释变量、分支和循环等通用编程思想，而是说明它们在 Python 中的表达方式、常见陷阱和标准库用法。讲解优先使用 JavaScript 或前端开发经验作类比，但不要求学习者安装前端框架或第三方 Python 包。

## 目标

- 提供 18 节可独立完成的自包含课程。
- 让每节讲解、练习和隐藏测试围绕同一组学习目标。
- 让学习者掌握 Python 基础语法、函数、模块、文件、异常和测试。
- 使用 Python 标准库完成可运行、可测试的本地日志审计器。
- 保留现有本地执行、草稿保存和逐节完成流程。
- 用内容完整性门禁防止新增空课、占位课或无需编码即可通过的练习。

## 非目标

- 不覆盖数据科学、机器学习、Web 框架或第三方包。
- 不替代现有 `python/project-tutorial.md` 中的 API 与 pandas 项目。
- 不修改 Python RPG、Go 或 Rust 课程。
- 不增加账号、云同步、遥测或远程代码执行。
- 不增加多文件在线编辑器；所有练习提交一个 Python 文件。
- 不为极端竞态、跨版本迁移或未复现边界增加状态机和测试矩阵。

## 课程架构

### 模块一：Python 表达方式

| 序号 | 课节 | 主要能力 | 练习产出 |
|---|---|---|---|
| 1 | 运行、变量与字符串 | 理解脚本执行、变量绑定、字符串和 f-string | 生成一条格式化日志摘要 |
| 2 | 条件、比较与真值 | 使用条件表达式、比较和 Python 真值规则 | 给日志记录分配严重级别 |
| 3 | 列表、元组与切片 | 使用序列、索引、切片和不可变数据 | 截取并整理最近的日志记录 |
| 4 | 字典与集合 | 使用键值映射、去重和成员检查 | 统计来源并提取唯一标签 |
| 5 | 循环、`enumerate` 与推导式 | 遍历数据并选择合适的简洁表达 | 为异常记录生成带编号摘要 |

### 模块二：可复用程序

| 序号 | 课节 | 主要能力 | 练习产出 |
|---|---|---|---|
| 6 | 用函数汇总日志 | 定义输入、处理和返回值明确的函数 | 实现 `summarize(lines)` |
| 7 | 参数、返回值与作用域 | 使用位置参数、关键字参数、默认值和局部作用域 | 编写可配置的级别统计函数 |
| 8 | 类型提示与数据类 | 用类型提示和 `dataclass` 表达记录模型 | 建立 `LogEntry` 数据模型 |
| 9 | 模块、导入与标准库 | 组织模块并选择标准库能力 | 将日志解析逻辑整理为可导入模块 |

### 模块三：文件与可靠性

| 序号 | 课节 | 主要能力 | 练习产出 |
|---|---|---|---|
| 10 | `pathlib` 与文本文件 | 使用跨平台路径和上下文管理器读写文本 | 读取一个日志文件并返回有效行 |
| 11 | 解析日志记录 | 拆分、清理和校验文本记录 | 把文本行转换为 `LogEntry` |
| 12 | JSON 与 CSV | 读取和生成常见结构化格式 | 输出统计结果的 JSON 与 CSV |
| 13 | 异常、校验与错误信息 | 捕获预期故障并生成可执行的错误信息 | 区分缺失文件、坏记录和空输入 |
| 14 | `unittest`、临时目录与调试 | 编写行为测试并隔离文件夹具 | 为日志扫描与报告生成添加测试 |

### 模块四：日志审计器

| 序号 | 课节 | 主要能力 | 练习产出 |
|---|---|---|---|
| 15 | `argparse` 命令行入口 | 定义参数、帮助信息和退出行为 | 建立 `log_auditor.py` 命令行入口 |
| 16 | 扫描目录与筛选文件 | 遍历目录、筛选扩展名并稳定排序 | 收集待分析的日志文件 |
| 17 | 聚合统计与报告生成 | 组合解析、统计和序列化能力 | 生成 JSON 与 CSV 审计报告 |
| 18 | 集成、测试和交付 | 串联完整流程并验证成功与失败路径 | 完成可运行的本地日志审计器 |

现有 `python-functions-01` 内容保留并扩充为第 6 节。其课节 ID 可以继续使用，避免无收益的重命名。

## 单课内容契约

### 固定教学结构

每节课按相同顺序呈现：

1. 定位：模块、预计时间、前置课节和学习目标。
2. 概念讲解：2～4 个短小主题，每个主题包含解释、前端类比和代码示例。
3. 常见错误：错误现象、产生原因和修正方式。
4. 引导练习：任务背景、实施步骤和可观察的验收条件。
5. 编码区：加载独立 `starter.py`，并持续保存学习者草稿。
6. 分级提示：默认折叠，按顺序逐条展开。
7. 参考实现：加载独立 `example.py`，默认折叠并标注为参考答案。
8. 本节总结：列出掌握点及其与日志审计器的关系。

## 页面与交互

现有学习工作台继续作为唯一课程页面：

- 左侧导航按四个模块分组展示 18 节课程、完成状态和当前课节。
- 所有课节标题和目标均可浏览，避免未解锁内容完全不可见。
- 未解锁课节不能提交运行；完成当前课节后解锁下一节。
- 主区按固定教学结构展示正文、错误示例、练习、提示、参考实现和总结。
- 编码区、运行按钮和结果反馈保持在主要工作流内，长讲解不遮挡运行入口。
- 提示按层级展开；参考实现默认折叠。
- 展开控件支持键盘操作、可见焦点和明确的展开状态。
- 页面继续只验收桌面浏览器，不新增移动端课程布局要求。

## 本地执行数据流

```text
读取课程目录
  -> 校验 18 节元数据和内容文件
  -> 页面加载公开教学内容
  -> 恢复当前课节与草稿
  -> 提交 lessonId + code
  -> 本机临时目录执行 Python + 隐藏 unittest
  -> 返回分类结果
  -> 通过后记录掌握状态并解锁下一节
```

18 节均提交一个 Python 文件。第 15～18 节逐步扩充同一个 `log_auditor.py` 练习模型；隐藏测试在临时目录中创建所需文件夹具，不要求页面编辑多个文件。

课程沿用信任本地代码模型。代码只在学习者本机运行，不发送到远程服务。

## 运行结果与错误反馈

| 状态 | 页面反馈要求 |
|---|---|
| 通过 | 显示通过的行为、掌握证据和下一节入口 |
| 测试未通过 | 显示预期与实际差异，不暴露隐藏测试源码 |
| 语法错误 | 标出行号、错误原因和优先修正动作 |
| 运行时错误 | 显示异常类型、学习者代码位置和修正方向 |
| 超时 | 说明可能存在无限循环，并允许修改后重试 |
| Python 不可用 | 显示解释器检测结果和本地配置方式 |
| 请求无效 | 指出课节或代码缺失，不进入执行 |

错误说明使用直接、可执行的教学语言。只处理常见本地故障，不为恶意代码或极端进程竞态增加隔离协议。

## 学习进度

- 草稿、当前课节和完成状态继续保存在浏览器本地。
- 只有隐藏测试通过才标记课节完成。
- 已完成课节可以反复运行，不清除完成状态。
- 重置本节只恢复该节起始代码，不修改其他课节进度。
- 浏览器存储损坏时恢复为空状态，并允许继续阅读和运行第一节。
- 不增加跨设备同步或历史格式迁移。

## 内容完整性门禁

自动检查以下课程不变量：

- 课程目录恰好包含 18 节，课节 ID 唯一、顺序连续，并归入 4 个模块。
- 每节包含目标、概念讲解、常见错误、练习步骤、验收条件、提示和总结。
- 必填数组非空，文本中不存在 `TODO`、`TBD` 或同类占位。
- 每节存在 `starter.py`、`example.py` 和 `hidden_test.py`。
- 18 份参考实现都能通过对应隐藏测试。
- 18 份起始代码都不能直接通过对应隐藏测试。
- 公开课程接口不包含隐藏测试内容。

参考实现通过与起始代码失败可以由一个表驱动测试循环完成，不为每节复制独立测试文件。

## 测试范围

自动化测试只覆盖：

- 课程内容契约与 18 节文件完整性。
- 所有参考实现通过、所有起始代码未直接通过。
- 公开接口隐藏私有测试内容。
- Runner/HTTP 的一次正常执行和一次关键失败执行。
- 本地进度的“通过后解锁”和“损坏存储恢复为空状态”。

不测试私有辅助函数、字段转发、CSS 细节、完整错误状态矩阵、极端竞态或未复现边界。不执行全仓测试。

## 人工验收

- 在桌面浏览器完成第 1、6、10、15、18 节，覆盖四个模块和结业项目。
- 检查长讲解、代码块、分级提示、错误反馈和课节导航没有遮挡或横向溢出。
- 用最终日志审计器读取测试日志目录，实际生成 JSON 与 CSV 报告。
- 刷新页面后确认草稿、当前课节和完成状态能够恢复。
- 逐节抽查讲解与练习一致，不存在“讲 A、测 B”。

## 完成标准

以下条件全部满足后，本次课程内容补全才算完成：

- 18 节均具备可读正文、可运行练习、参考实现和有效隐藏验收。
- 学习者无需外部教材即可理解任务并修正关键错误。
- 四个模块形成从 Python 表达到本地自动化项目的连续递进。
- 结业日志审计器能够扫描日志、统计结果并生成 JSON 与 CSV 报告。
- 自动化门禁和限定的本地浏览器主流程全部通过。
- Python RPG、Go 和 Rust 课程未被修改。

## 风险与控制

### 内容数量增加导致质量不均

使用固定教学结构、表驱动内容门禁和逐节人工抽查。先保证每节讲解、练习和测试一致，再处理表达优化。

### 长正文挤压编码工作流

保留现有工作台边界。提示和参考实现折叠显示，正文按小节组织，运行入口始终处于主要工作流内。

### 结业项目超出单文件执行模型

把日志审计器限定为单个 `log_auditor.py`。隐藏测试负责建立临时日志目录和验证输出，不增加多文件编辑能力。

### 测试数量随课节线性膨胀

内容不变量、参考实现和起始代码使用表驱动循环验证。行为测试只保留正常路径和一个关键失败路径。
