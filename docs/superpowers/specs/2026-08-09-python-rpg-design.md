# 奥术工业幻想 Python RPG 设计

## 状态

设计已通过对话分节确认，等待用户审阅书面规格。本文是首个可玩切片的产品设计，不是实现计划。

## 目标

为已经具备其他语言编程经验、但不熟悉 Python 的成年人，提供一款真正可玩的回合制战术 RPG。玩家通过探索、战斗、调试和自动化逐步掌握 Python 的写法、惯用法和运行模型。

Python 是玩家在世界中施法、操控队友、修复机关和制定战术的真实工具，而不是附加在题库上的积分系统。

## 非目标

- 不做编程启蒙，不重复解释变量、循环和函数的通用概念。
- 首版不做账号、云端存档、多人联机或公开远程代码执行。
- 首版不同时上线 Go 和 Rust。
- 首版不实现开放世界、复杂经济、装备词缀、数据科学库或异步 Python。
- 不把现有 `python/` 课程页面直接改造成 RPG；现有课程继续独立可用。

## 用户与成功标准

### 目标用户

已有 JavaScript、Go、Java、C# 等语言经验，想快速进入 Python 真实项目的成年人。

### 首版成功标准

- 玩家可以在 60～90 分钟内完成一个独立战役切片。
- 玩家至少用 Python 完成变量与属性读取、条件、循环、集合、函数、异常、生成器、模块和测试等任务。
- 玩家能看到代码执行轨迹：代码行、变量值、角色动作和战局变化互相对应。
- 同一个关卡输入和随机种子可以稳定重放，失败原因可复现。
- 学习收益会改变玩法：从手动行动逐步升级为技能函数、条件策略和整队自动化。

## 核心体验

玩家扮演规则工程师，在奥术工业大陆中修复失控的规则炉心。

核心循环：

```text
探索城镇与遗迹
→ 接受有实际战斗目标的任务
→ 观察敌人、地形与队友状态
→ 手动行动或修改 Python 战术
→ 运行代码并逐步回放战斗
→ 根据代码行、变量和事件轨迹调试
→ 获得装备、技能槽与自动化能力
→ 重构战术，应对更复杂的战场
```

编码参与度采用渐进式自动化：

- 前期：修改参数、补全表达式，熟悉 Python 语法差异。
- 中期：编写函数、推导式、生成器和异常策略，形成可复用技能。
- 后期：组合队友 AI、资源调度和战斗规则，让整支队伍自动协作。

玩家失败时看到的不是单一“答案错误”，而是具体代码行执行后哪个角色做了什么、变量如何变化、战局为何崩溃。

## 世界与语言战役

世界是一座由规则炉心维持的奥术工业大陆。炉心失衡后，三个区域出现不同灾害。三条战役共享主角、队友、装备外观、世界地图、主线事件、成就、存档和战斗回放格式；不共享代码、课程顺序、运行器、语言专属敌人机制和 Boss 判定。

- **Python：变形沼泽与自动化遗迹**
  - 主题：快速试错、动态数据、自动化。
  - 重点：Python 数据模型、可迭代对象、推导式、函数式工具、异常、模块与脚本工程。
- **Go：并发工坊与物流城邦**
  - 主题：多人协作、任务调度、稳定服务。
  - 重点：显式错误、接口、结构体、goroutine、channel、`select`、HTTP 和测试。
- **Rust：所有权熔炉与边界要塞**
  - 主题：资源所有权、契约和高可靠系统。
  - 重点：所有权、借用、生命周期、`Option`、`Result`、trait、迭代器、线程安全和异步。

解锁顺序为 Python → Go → Rust；已经掌握某门语言的玩家可以跳过剧情教学，只保留诊断测试和战斗关卡。

## 首发垂直切片

- 1 个据点：锈叶前哨站。
- 1 张地牢地图：失控的自动化遗迹。
- 3 个普通敌人：护甲傀儡、巡逻蜂群、过热核心。
- 1 个 Boss：递归炉心。
- 3 名可招募队友，每名队友暴露不同状态字段和动作接口。
- 8～10 个短关卡，单关 5～12 分钟。
- 首次通关时长约 60～90 分钟。

关卡与 Python 能力映射：

| 关卡 | Python 重点 | 游戏目标 |
|---|---|---|
| 1 | 变量、属性读取、布尔表达式 | 让侦察兵避开危险地格 |
| 2 | `if / elif / else` | 根据敌人护甲选择攻击 |
| 3 | `for` 与 `range` | 让工蜂依次修复多个节点 |
| 4 | 列表、字典、索引 | 管理队伍和背包 |
| 5 | 函数与默认参数 | 制作可复用技能 |
| 6 | 推导式与 `filter` | 快速筛选目标 |
| 7 | 异常与上下文管理 | 处理过热、资源耗尽和失败回合 |
| 8 | 生成器与迭代器 | 让队伍按需处理事件 |
| 9 | 模块与测试 | 重构技能库 |
| 10 | 综合 Boss | 用完整策略击败递归炉心 |

## 技术架构

首发为 Web、本地优先，并为未来在线发布预留接口。

```text
rpg/
├── game/                 # 与语言无关的 RPG 内核
│   ├── world/            # 地图、单位、地形、任务
│   ├── combat/           # 回合制模拟、随机种子、回放
│   ├── progression/      # 经验、装备、技能槽、解锁
│   ├── save/             # 本地存档，未来可替换云存档
│   └── ui/               # 战棋界面、编辑器、反馈面板
├── content/
│   ├── shared/           # 世界、剧情、地图、敌人、通用任务
│   ├── python/           # Python 课程包与关卡测试
│   ├── go/               # Go 课程包与关卡测试
│   └── rust/             # Rust 课程包与关卡测试
├── runners/
│   ├── protocol/         # 统一执行请求和结果协议
│   ├── python/           # Pyodide Worker 适配器
│   ├── go/               # 本地 / 容器 Go 执行器适配器
│   └── rust/              # 本地 / 容器 Rust 执行器适配器
└── tools/
    └── content-check/    # 关卡数据、测试与资源校验
```

游戏内核不解析 Python、Go、Rust。运行器只负责执行代码、限制能力、产生动作和诊断。关卡只依赖统一的 `WorldView`、`Action`、`TraceEvent` 和测试断言。

统一执行请求：

```json
{
  "language": "python",
  "questId": "python-marsh-03",
  "sourceCode": "def plan(world): ...",
  "seed": 1842
}
```

统一执行结果：

```json
{
  "status": "passed",
  "actions": [
    {"actor": "player", "type": "move", "to": [4, 2]},
    {"actor": "player", "type": "cast", "skill": "repair", "target": "gate"}
  ],
  "trace": [
    {"line": 2, "event": "读取 gate.integrity", "value": 18}
  ],
  "diagnostics": []
}
```

Python 首版继续使用 Pyodide Worker；Go 和 Rust 后续接本地服务或隔离容器。存档首版使用 `localStorage`，通过 `SaveStore` 接口隔离，未来可替换为云存档。所有战斗使用显式随机种子。

## 素材策略

首发视觉基线为 Tiny Swords 的 64px 战棋尺度，后续使用铜管机械、符文能源和深色遗迹地表做奥术工业化改造，不混入 Ninja Adventure 的 16px 像素密度。

- Tiny Swords：可用于个人和商业项目，可修改；不得重新分发或单独转售素材包。
- Kenney：资产页标注 CC0，可用于商业项目且无需署名。
- Ninja Adventure：CC0，可作为备用的角色、怪物、Boss、音效和 UI 素材来源，但不作为首发主视觉。
- OpenGameArt：仅使用逐项明确标注许可证的资源，并在资产清单中记录作者、来源、许可证和修改说明。

素材目录必须维护 `ASSET-LICENSES.md`，禁止引入无法确认授权的图片、音乐、字体或生成素材。

## 状态与错误处理

必须分别覆盖加载中、运行中、通过、无输出、代码异常、编译/运行器不可用、超时、进度保存失败和存储损坏。错误反馈同时包含：用户可读解释、代码位置、事件轨迹和下一步调试入口。运行器不得将本机绝对路径、环境变量或敏感信息返回给页面。

## 测试策略

- 游戏内核：确定性战斗、动作合法性、随机种子重放、状态迁移和存档往返测试。
- 内容校验：关卡 ID、能力标签、动作白名单、隐藏测试和资源许可证清单校验。
- 运行器协议：通过、诊断失败、超时、输出截断、运行器不可用和非法请求。
- 浏览器验收：桌面与移动视口导航、代码编辑、运行反馈、回放、进度和草稿保存。
- 每新增一门语言，先通过同一协议的适配器契约测试，再添加语言专属关卡。
